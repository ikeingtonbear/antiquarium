# Quickstart: Refactor Tap UI

## Setup & Run

1. Ensure the backend (sharkd/sharkophagus) is running and accessible.
2. In the `web/` directory, install dependencies and start the development server:
   ```bash
   npm install
   npm run dev
   ```

## Testing

Run unit tests for the components using Vitest:
```bash
npm run test
```
