# Quickstart & Verification: Web UI Adjustments and Accessibility Improvements

This guide details verification steps for the UI adjustments.

## Verification Checklist

1. **Settings Menu Label**:
   - Open the settings menu in the bottom-right corner.
   - Verify the menu option displays exactly "Info" with no additional text.

2. **Footer Version info**:
   - Verify that the footer text on the main screen says "Sharkophagus online" and does NOT contain any version string.
   - Open the Info modal and verify that the version string (e.g. `v1.0.0`) is shown in the badge at the top of the modal.

3. **Close Button**:
   - Upload a pcap and view the analysis modal overlay.
   - Verify the button at the bottom of the modal is labeled exactly "Close".
