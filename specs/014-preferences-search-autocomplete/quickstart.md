# Quickstart

To use the autocomplete search feature in the preferences settings:

1. Open the UI and navigate to the Config (Preferences) Modal.
2. Focus the search input field.
3. Start typing a preference name (e.g., `tcp.op`).
4. Wait briefly (approx 300ms) for the autocomplete dropdown to appear.
5. Use the mouse to click an option, or the keyboard up/down arrows and `Enter` key to select a suggestion.
6. The search field will populate with the selected preference, instantly filtering the view.
